RequeXU: Work Order Management System

An Adaptive Web Application for Streamlined Work Order and Dispatch Management

Project Overview

The Physical Plant Office (PPO) is an integral part of Xavier University, handling physical infrastructure and providing manpower for utilities and functions across different campuses.

Problem Statement

Previous work order processes dealt with paper-based systems. The inherent issues with pen-and-paper processes, amplified by the scale of operations across different campuses, proved ample reason for implementing better technologies and streamlining.

Solution Features

  • Request List Functions: Accurate detailing of work order requests
  • Work Order Modules: Centralized management of different campus orientations
  • Monitoring & Dispatch: Controlled monitoring and dispatch of manpower and resources
  • Notifications: In-app and email notifications for push notifications
  • Analytics: Graphical and analytical data for monitoring work orders

Impact

The system provides an accessible work order submission form without manual processes, along with centralized dispatch and management, facilitating service for students, staff, and faculty across all Xavier University campuses.

Technologies Used

MERN Stack MongoDB Express.js React Node.js Google OAuth Email Integration
