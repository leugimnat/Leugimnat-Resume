# Miguel Antonio V Tan - Resume Website

A modern, responsive personal portfolio and resume website showcasing my professional experience, education, and projects as an aspiring software developer and IT professional.

## 🌟 Features

- **Responsive Design**: Fully responsive layout that works seamlessly across desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean, professional design with smooth animations and transitions
- **Interactive Navigation**: Fixed navbar with smooth scrolling to different sections
- **Dynamic Content**: Typing animation effect for role descriptions
- **Portfolio Showcase**: Dedicated sections for projects, experience, and education
- **Contact Integration**: Contact form and social media links
- **Performance Optimized**: Minified CSS and optimized images for fast loading

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript
- **Styling**: Custom CSS with modern features (Flexbox, Grid, CSS Variables)
- **Fonts**: Google Fonts (Poppins)
- **Icons**: Font Awesome
- **Responsive Design**: CSS Media Queries
- **Performance**: Minified CSS for production

## 📄 Pages

- **Home** (`index.html`): Introduction, about section, and contact information
- **Education** (`education.html`): Academic background, certifications, and skills
- **Experience** (`experience.html`): Work experience, projects, and achievements

## 🎯 Key Sections

### Home Page
- Hero section with profile image and introduction
- About section with professional summary
- Contact form and social media links

### Education Page
- Academic timeline with degrees and institutions
- Certifications and ongoing learning
- Skills categorized by technology areas
- Educational gallery and achievements

### Experience Page
- Professional work experience timeline
- Project portfolio with detailed descriptions
- Technical skills and achievements
- Career statistics and milestones

## 🔧 Customization

To customize this website for your own use:

1. Replace personal information in HTML files
2. Update images in the `images/` directory
3. Modify color scheme in CSS variables
4. Update social media links and contact information
5. Add or remove sections as needed

## 📈 Performance

- Optimized images with lazy loading
- Minified CSS for faster load times
- Efficient CSS animations and transitions
- Mobile-first responsive design approach
