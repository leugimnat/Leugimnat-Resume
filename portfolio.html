RequeXU: Work Order & Dispatch Management

Project Overview

The Physical Plant Office (PPO) is an integral part of Xavier University, handling physical infrastructure and providing manpower for utilities and functions across different campuses. This project addressed the inefficiencies of their paper-based work order processes.

Problem Statement

Previous work order processes dealt with paper-based systems, creating inherent issues amplified by the scale of operations across multiple campuses. This provided ample reason for implementing better technologies and streamlining processes.

Solution & Impact

The system provides an accessible work order submission form without manual processes, along with centralized dispatch and management capabilities. It successfully facilitates and serves students, staff, and faculty across all Xavier University campuses.

Screenshots
Key Features:
  • Request list functions with accurate work order detailing
  • Centralized management across different campus orientations
  • Controlled monitoring and dispatch of manpower and resources
  • In-app and email notifications for real-time updates
  • Graphical and analytical data for work order monitoring
  • Google OAuth integration for secure authentication
  • Mobile-responsive Progressive Web App (PWA)
